# Сбор палетов 📦

Веб-приложение для ТСД: сканирование кодов → Excel-файл (коды + SSCC) → отправка в Telegram.

Работает на GitHub Pages, сбор данных — офлайн, интернет нужен только в момент отправки.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Разметка (3 экрана + модалка) |
| `style.css` | Стили (мобильный-первый, крупные кнопки под ТСД) |
| `app.js` | Вся логика: строки, SSCC, Excel, отправка |
| `config.js` | **Настройки — заполняется один раз** |
| `sw.js` | Service worker (офлайн-режим) |
| `manifest.json`, `icon.svg` | PWA: можно добавить на рабочий стол ТСД |

## 1. Настройка Telegram (один раз, ~5 минут)

### Шаг A. Создаём бота

1. Откройте Telegram, найдите **@BotFather** (официальный бот создания ботов).
2. Напишите ему команду `/newbot`.
3. Он спросит имя бота — например `МойПалетБот` (можно любое).
4. Потом username — должен заканчиваться на `bot`, например `moy_palet_bot`.
5. В ответ BotFather пришлёт **токен** — строку вида `123456789:AAF...xyz`.
   Вставьте её в `config.js` в поле `TELEGRAM_BOT_TOKEN`.

### Шаг B. Узнаём, куда бот будет слать файлы (chat_id)

1. Откройте в Telegram своего нового бота (по username из шага A) и нажмите **Start**.
   Без этого бот не сможет писать вам — это правило Telegram.
2. Узнать свой числовой ID: напишите боту **@userinfobot** (или **@getmyid_bot**)
   — он мгновенно ответит вашим ID, вида `123456789`.
   Вставьте это число в `config.js` в поле `TELEGRAM_CHAT_ID`.

Готово. Если нужно слать файлы не себе, а в группу — добавьте бота в группу
и впишите в `TELEGRAM_CHAT_ID` адрес группы вида `@nasha_gruppa`.

### Проверка

Откройте `index.html`, создайте палет, отсканируйте пару кодов, нажмите
«Создать палет» → введите название → «Отправить». Файл должен прийти в Telegram.

Если Telegram не настроен (поля в `config.js` пустые) — приложение просто
скачает файл на устройство. Так же оно поступит, если интернета нет
в момент отправки.

## 2. Запуск локально

- Просто откройте `index.html` двойным кликом — базовые функции работают.
- Для полного теста (офлайн-режим) нужен локальный сервер:
  `python -m http.server` в этой папке → открыть `http://localhost:8000`.

## 3. Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например `palety`) и залейте все файлы.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
   Branch: main / (root)** → Save.
3. Через минуту сайт будет доступен по адресу `https://ваш-логин.github.io/palety/`.
4. Откройте этот адрес на ТСД, затем в меню браузера — «Добавить на главный экран»,
   чтобы приложение открывалось как обычная программа.

## 4. Обновление приложения (важно из-за кэша!)

После первого открытия service worker кэширует все файлы для офлайн-работы.
Поэтому после обновления файлов на GitHub Pages **увеличьте версию кэша**
в `sw.js` в первой строке: `palety-v1` → `palety-v2` и т.д.
Иначе устройства будут показывать старую версию.

## 5. Как устроен SSCC

`[случайная 1–9] + [префикс компании 4643721954] + [6 случайных цифр] + [контрольная цифра]`

Итого 18 цифр, контрольная считается по стандартному алгоритму GS1 (mod 10).
Префикс меняется в `config.js` (поле `SSCC_PREFIX`).

## 6. Структура Excel

| Колонка A | Колонка B |
|---|---|
| отсканированный код 1 | SSCC |
| отсканированный код 2 | SSCC |
| … | … |

**SSCC генерируется один на весь палет и повторяется в каждой строке.**

Имя файла = название палета, введённое при отправке (`.xlsx`).

## Примечания

- Токен бота лежит в открытом виде в коде страницы (GitHub Pages — статика).
  Кто найдёт токен, сможет слать сообщения вашему боту. Если это станет проблемой —
  можно спрятать токен за Cloudflare Worker (бесплатно), спросите.
- Черновик палета хранится в браузере: если ТСД перезагрузился во время сбора,
  коды не пропадут (до отправки палета).
- Почту (EmailJS) можно добавить позже аналогично Telegram.
